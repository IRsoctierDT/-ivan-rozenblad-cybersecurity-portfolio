# Risk Assessment & Audit

Security risk assessments and internal audit deliverables aligned to the NIST Cybersecurity
Framework (CSF) — asset inventory, risk scoring, controls gap analysis, and remediation
recommendations.

| Artifact | Description |
|---|---|
| `audit-scope-and-goals.docx` | Definition of audit scope, goals, and boundaries aligned to the NIST CSF. |
| `botium-toys-risk-assessment-report.docx` | Full internal security risk assessment for a sample organization (Botium Toys): asset inventory, risk scoring, controls and compliance checklist, and remediation recommendations. |
| `security-risk-assessment-report.docx` | Structured security risk assessment documenting threats, vulnerabilities, likelihood/impact, and prioritized mitigations. |

> _Note: this domain folder was added beyond the original layout to house the
> governance / risk / audit deliverables, which don't fit the technical domain folders._
