# Agent Trust Broker

**Status:** Active — reference implementation  
**Repos:** https://github.com/IRsoctierDT/agent-trust-broker

Zero-trust identity and authorization for agent fleets: short-lived scoped identities, attenuating delegation, allow/deny/escalate decisions, hash-chained audit. Fail-closed by design. Intended as the identity gate in front of privileged tool dispatch (including inside IANUA).
