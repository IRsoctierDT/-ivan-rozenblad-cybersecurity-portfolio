# IANUA-Broker (mcpscan)

**Status:** Shipped — PyPI [`ianua-broker`](https://pypi.org/project/ianua-broker/) v1.5.2  
**Repos:** https://github.com/IRsoctierDT/IANUA-Broker  
**Docs:** https://irsoctierdt.github.io/IANUA-Broker/

Offline-by-default security posture scanner for MCP servers and local AI-agent setups. Inventories agent hosts, surfaces exposure and risky configuration, grades posture, and can emit SARIF for code-scanning workflows. CLI entrypoint: `mcpscan`.

### Why it matters
Organizations are adopting agent tool bridges faster than they are inventorying them. Broker makes local MCP/agent posture visible without requiring a cloud phone-home.
