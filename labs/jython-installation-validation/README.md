**Status:** 🚧 In progress — content and screenshots to be added

## Objective

Install Jython (the Python implementation for the Java Virtual Machine) and validate that
the environment is correctly configured for running Python-based tooling on the JVM.

## Planned Contents

- **Environment prerequisites** — JDK/JRE version requirements and `JAVA_HOME` setup.
- **Installation steps** — installer execution and target directory selection.
- **Validation tests** — interactive shell startup, `sys.version`, and a sample script run.
- **Troubleshooting** — see [`artifacts/troubleshooting-notes.md`](./artifacts/troubleshooting-notes.md).
